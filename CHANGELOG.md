## [Unreleased]

## [1.1.0] - 2026-09-15

### Changed

- Repository renamed `himalayan-expedition-success` and reorganized: scripts in `src/`, dataset in `data/`, report, slides, talk script and figures in `docs/`
- The scripts locate the data and the figures from the repository root and run from any working directory
- The intermediate datasets (`exped_depart.csv`, `exped_clean.csv`) are no longer committed: the second script regenerates them
- Python sources linted and formatted with Ruff
- README rewritten in English: problem, pipeline, the two traps, results, getting started, repository structure and quality checks

### Added

- Compiled report (`docs/report-fr.pdf`)
- End-to-end pytest tests of the five scripts (printed facts, written files, figures, accuracy and coefficients)
- CI: Ruff and pytest, the pipeline run end to end with the figures as artifact, markdownlint and lychee, dependency review and CodeQL
- Dependabot for the Python dependencies and the GitHub Actions, with auto-merge of patch and minor updates once the required checks pass
- MIT License, contributing guide, code of conduct, security policy, citation metadata, issue forms and pull request template
- Pinned dependencies in `requirements.txt` and `requirements-dev.txt`

### Removed

- The course slides (`Cours/`), teaching material of the instructor that is not ours to redistribute
- The placeholder `SECURITY.md` and `dependabot.yml` generated by GitHub, replaced by real ones

## [1.0.0] - 2026-06-05

Version presented at the defence at the end of the project week.

### Added

- Exploration of the Himalayan Expeditions dataset: selection of 8 predictors known before departure, data leakage analysis
- Wrangling: cleaning, encoding, `ratio_hired` feature, one-hot encoding of the season and of the 8 most attempted peaks
- Five figures, three handcrafted features tested against the data (one kept, two rejected)
- Logistic regression in a scikit-learn pipeline: holdout versus cross-validation, grid search on the regularization, confusion matrix and coefficients (69.3 % of accuracy against a 55 % baseline)
- Report, slides and talk script (French)
